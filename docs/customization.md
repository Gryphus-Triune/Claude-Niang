# 自定义资源说明

日常换形象、语录和音效，使用挂件右键菜单即可。本文供需要维护默认资源或墨镜位置的开发者参考。

## 形象与图标

默认形象为 `claude-niang/assets/claude-niang.png`，桌面扩展图标为 `claude-niang/extension/icon.png`。更换默认资源时，需要同时检查角色裁切、透明边缘、点击区域和扩展图标的显示效果。

用户自行添加形象时，建议使用透明背景的正方形 PNG、大头半身且撑满画布，1024～2048 像素；导入上限为边长 4096、文件 20 MB。用户导入的图片不应提交到仓库或打进发布包。

## 音乐律动的墨镜标定

默认形象的墨镜位置保存在 `claude-niang/assets/claude-niang.glasses.json`。其中的 SHA-256 必须与形象图片一致。

更换默认图片后，需要重新标定位置并更新校验值；图片与标定文件不匹配时，程序不显示墨镜，避免位置错误。自行导入的形象没有相应标定，默认不戴墨镜。

维护这组资源后，请检查默认形象、音乐律动、墨镜位置和不同缩放下的效果，并将图片与标定文件一起提交。

## 文档预览

`docs/images/quota-preview.png` 是由本地界面生成的额度气泡预览，使用示例数据，不代表任何账号的实际额度。预览应与当前界面保持一致。

新增或移动文档图片时，同时更新 README 引用及 `tools/release.mjs` 的文档资源白名单，确保发布 ZIP 解压后也能显示。
