# Claude 娘 · Claude 桌面端额度挂件

<img src="claude-niang/extension/icon.png" alt="Claude 娘" width="160" align="right">

在 Windows 上给 Claude 桌面端的右下角放一个小角色。点她就能看到当前套餐、5 小时额度、每周额度、分模型的每周额度、额外用量和重置时间；再点气泡可以翻页或看语录。

- 额度只在你主动操作时读取：启动、恢复窗口、登录完成、自动语录都不会去查询。
- 数据来自 claude.ai 的网页用量接口，不调用模型，不消耗 API Key 额度。
- 附带一个 Claude 桌面扩展，可以直接在对话里问 Claude「我还剩多少额度」。
- 开启「音乐律动」后，她会跟着电脑里正在播放的音乐打拍子，还会戴上墨镜。

基于 [GPT 娘 1.3.5](https://github.com/T7moris/GPT-Niang)（MIT）改写，借鉴了[小鲸鱼余额挂件](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)的提醒与记账思路。**非 Anthropic 官方产品。**

## 安装前准备

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（x64 或 ARM64）。macOS / Linux 不支持。 |
| Claude | 已安装 Claude 桌面端（官网安装版或微软商店版都可以）。 |
| Node.js | 20 或更新，建议安装 [Node.js 官网的 LTS 版](https://nodejs.org/)。安装器会在 PATH 和常见安装位置里查找。 |
| WebView2 | Microsoft Edge WebView2 运行时。Windows 11 自带；缺少时安装器会给出[微软官方下载入口](https://developer.microsoft.com/microsoft-edge/webview2/)。 |
| 账号 | 能登录 claude.ai 的账号。Free 或部分组织可能不提供额度窗口。 |

不需要管理员权限。每个 Windows 用户使用自己的登录、设置和数据。

## 下载与安装

1. 下载本仓库：在 GitHub 页面点 **Code → Download ZIP**（有 Releases 时也可以下载发布包）。
2. 建议先右键 ZIP → **属性** → 勾选 **解除锁定** → 确定，再解压。没做也没关系，安装器会自动清除这个文件夹里的下载标记。
3. **完整解压**，不要在压缩包里直接运行。把整个文件夹放到以后不会移动的位置，例如 `%LOCALAPPDATA%\Programs\Claude娘额度挂件`。
4. 双击 **安装Claude娘.cmd**。如果 Windows 提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。安装器会检查依赖，并登记当前用户的开机自启；计划任务不可用时会改用「启动」文件夹。
5. 按提示在 Claude 娘自己的小窗口里登录 claude.ai，以后也可以双击 **登录Claude账号.cmd**。
6. 打开 Claude 桌面端主窗口，点右下角的角色或 ↻，读取一次额度。

用 Google 登录时如果提示浏览器不安全，可以改用 Continue with email，按页面提示用邮箱验证码登录。需要人机验证时，请在登录窗口里自己完成，挂件不会自动处理验证。

挂件的登录和 Claude 桌面端是分开的。两边登录了不同账号时，显示的是**挂件登录的账号**。有多个组织时可以在右键菜单里切换。

## 日常使用

- **点角色**：展开额度气泡并读取一次。同一组织 15 秒内的重复点击会复用刚才的结果，同时发出的多个请求只读取一次。
- **点气泡**：下一页 → 语录 → 收起。
- **↻ / 右键「刷新额度」**：手动刷新。
- **连续失败**：连续 3 次读取失败后暂停 30 秒，这段时间里点击不会查询，状态栏会提示还要等几秒；时间到了不会自动重试。读取成功一次、重新登录或切换组织后重新计数。
- **右键 → Claude 账号 → 切换组织**：读取选定的组织，切换时旧组织的额度会先隐藏。
- **鼠标停在气泡上**：查看组织、时间、金额和完整说明。
- **低额度 / 重置提醒**：只在手动读取到新结果后判断，按组织区分，不会为了提醒去后台查询。
- **今日观测统计**：从本机当天第一次成功读取起，累计观察到的每周额度增量（单位是百分点）。这是采样估算，不是完整账单、消息数或 token 数。

气泡里会标出上次更新时间。断网或接口格式变化时保留上次成功的数据；重置时间已到但还没重新读取时，会提示等待刷新，不会把旧的剩余值当成已恢复的额度。

| 文件 | 作用 |
|---|---|
| 安装Claude娘.cmd | 安装，或在原位置重新登记挂件 |
| 打开Claude娘.cmd | 手动启动挂件（不会因此读取额度） |
| 登录Claude账号.cmd | 打开挂件自己的登录窗口 |
| 检测套餐.cmd | 主动读取一次，用于排查套餐和额度 |
| 停用Claude娘.cmd | 关闭挂件并移除开机自启，保留文件、设置和登录 |

## 在 Claude 对话里问额度

先安装并打开挂件，在挂件里登录并读取一次额度。然后双击 `Claude桌面扩展\claude-niang-usage.mcpb`，在 Claude 桌面端里安装这个扩展。

问「我还剩多少额度？」时，扩展读取本机保存的快照，并告诉你数据时间；明确说「刷新额度」时，才让正在运行的挂件重新读取。挂件没在运行时，会说明刷新没有成功，并尽量给出上次保存的数据。

扩展不会创建聊天、不会调用模型，也接触不到登录 Cookie。数据目录一般不用改；如果自定义了挂件数据位置，在扩展设置里选择对应的 `state` 文件夹。

## 换形象、语录、音效和音乐律动

- **形象**：右键 → 更换形象 → 添加形象，选择自己的图片。建议透明背景的正方形 PNG，大头半身、角色撑满画布，1024～2048 像素；上限为边长 4096、文件 20 MB。
- **语录**：右键 → 编辑我的语录，一行一句；也可以恢复内置语录，或在「自动语录」里定时显示。
- **音效**：右键 → 声音与点击，可以换成最长 5 秒的 WAV，导入后会转成本地缓存。
- **音乐律动**：右键 → 音乐律动。挂件听电脑正在播放的声音找节拍，角色跟着拍子弹跳，两边出现音箱，窗口上方挂一个灯球；可以把她拎起来甩出去。声音只在本机分析，不保存也不上传。
- **墨镜**：音乐律动时，默认形象会戴上墨镜。墨镜的位置记在图片旁边的标定文件里（`claude-niang\assets\claude-niang.glasses.json`），文件里有图片的校验值；换了图片就不再显示墨镜，免得戴歪。自己添加的形象没有标定，所以不戴墨镜。

## 更新、搬家与卸载

**更新**：先运行「停用Claude娘.cmd」，把新版本的文件覆盖到**同一个文件夹**（保留里面的 `installation.json`），再运行「安装Claude娘.cmd」。设置和登录保存在程序文件夹之外，不受影响。如果装过桌面扩展，再双击一次新的 `.mcpb` 即可更新。

**搬家**：先运行「停用Claude娘.cmd」，再把整个文件夹移到新位置并重新安装。不要同时保留两个已安装的副本，它们会争用同一份开机启动登记。

**彻底卸载**：先运行「停用Claude娘.cmd」，再删掉程序文件夹和 `%LOCALAPPDATA%\ClaudeNiang`（后者包含挂件自己的登录）。桌面扩展请在 Claude 桌面端的设置里移除。

## 数据与隐私

- 登录保存在当前 Windows 用户的 `%LOCALAPPDATA%\ClaudeNiang\webview`；额度快照、设置和统计保存在旁边的 `state`。
- 挂件不读取你常用浏览器或 Claude 桌面端里的登录，也不把 Cookie 交给 Node.js 部分或桌面扩展。
- 读取额度时只访问 claude.ai 的组织、用量、必要的套餐信息和余额接口；组织和余额会缓存，减少重复请求。
- 没有自动更新、遥测或任何第三方上传。

claude.ai 的网页接口不是公开 API，随时可能变化而失效。请遵守 Anthropic 的服务条款；遇到限流、验证或账号不可用时，挂件会提示原因，并等你下一次操作。

## 排查问题

- **没有出现**：打开 Claude 主窗口、取消最小化，再双击「打开Claude娘.cmd」。
- **没有额度数字**：先登录，再点角色或 ↻。Free 等套餐没有额度窗口时会有说明。
- **内置浏览器组件检查失败**：重新运行一次「安装Claude娘.cmd」，它会清除下载标记；仍然失败时，检查是否安装了 WebView2 运行时。
- **提示「已连续失败 3 次」**：等提示的秒数过去再点 ↻；多半是网络、验证或登录的问题，先看提示里的原因。
- **已限流**：按提示等待后手动刷新，不会定时重试。
- **退出登录失败**：先关闭已打开的登录窗口，或等当前查询结束后再试。
- **安装失败**：查看程序文件夹 `claude-niang` 里的 `install-log.txt`。反馈时请删掉用户名、完整个人路径等信息，不要上传浏览器配置或 Cookie。
